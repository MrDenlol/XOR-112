# Changelog

## 0.1.0 — 2026-11-08

First public XOR-112 release.

- Native Rust/egui binary circuit editor with eight basic gate types.
- Editable 32-bit and 64-bit gate-level ALUs: addition, subtraction, multiplication, integer division and integer square root.
- Save/load, validation, truth tables, undo/redo and element navigation.
- Ribbon interface, Russian/English, three themes, grid snapping and animated wires.
- Persistent settings, including migration from the earlier BinaryLogic name.
- Renamed executable and Cargo package to `xor-112`; existing circuit formats preserved.
- Documentation, Windows package and cross-platform build workflow.
