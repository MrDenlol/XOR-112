# Changelog

## 0.2.0 — 2026-11-11

- Redesigned ribbon and rounded panels; one canvas with bottom-only zoom controls and icon-only fit action.
- Persistent independent visibility controls for the library and properties panels.
- Editable three-input majority and eight-input multiplexer examples.
- Circuit templates library: insert any non-ALU example as ordinary editable gates and wires, with snapping and one-step undo/redo.
- Fully blue accents, signals, wires and application icon in the blue theme.
- Rounded Help glyph, standard home/settings/table icons, curved undo/redo arrows, equal library squares and a tinted information icon.
- Fixed black gaps between rounded panels.
- Updated Russian/English documentation and screenshots; added the original XERJ Hub contributor badge.
- Preserved `.binary` compatibility, all three themes, binary-only signals and editable 32/64-bit ALUs.

## 0.1.0 — 2026-11-08

First public release: native Rust/egui binary circuit editor, eight basic gate types, editable 32/64-bit ALUs, save/load, validation, truth tables, undo/redo, two interface languages, three themes and persistent preferences.
